## 🤝 How to Contribute

### Reporting Issues

- Search existing issues first.
- Use the issue templates if available.
- Provide clear reproduction steps.
- Include environment details.

### Suggesting Enhancements

- Check the roadmap and existing discussions.
- Explain the use case and expected behaviour.
- Consider implementation complexity.

### Code Contributions

#### Development Setup

```bash
# Clone the repository
git clone https://github.com/hmlendea/map-of-nirn.git
cd map-of-nirn

# Open source assets in a vector graphics editor (e.g., Inkscape)
```

#### Making Changes

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes to SVG source assets.
4. Validate raster exports in an image viewer.
5. Commit with clear and descriptive messages.
6. Push to your fork.
7. Open a Pull Request.

#### Pull Request Guidelines

- Target the `master` branch.
- Keep PRs focused and atomic.
- Revise documentation if applicable.
- Ensure the CI checks pass.

### Code Style

Follow the project's coding standards:
- Maintain consistent SVG structure and naming conventions.
- Use Inkscape-compatible SVG features.

### Documentation

- Revise relevant docs for changes.
- Follow the documentation style guide.
- Preview changes locally if possible.
